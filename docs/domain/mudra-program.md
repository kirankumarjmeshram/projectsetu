# PMMY / MUDRA program definition

## Current version

`GOI.PMMY` uses version `2024-10-24-TARUN-PLUS`. The Department of Financial
Services records the 24 October 2024 enhancement from Rs 10 lakh to Rs 20 lakh
and its current official PMMY page confirms the boundaries and prior-repayment
condition.

| Category   | Requested credit                    |
| ---------- | ----------------------------------- |
| Shishu     | Rs 0 through Rs 50,000              |
| Kishore    | Above Rs 50,000 through Rs 5 lakh   |
| Tarun      | Above Rs 5 lakh through Rs 10 lakh  |
| Tarun Plus | Above Rs 10 lakh through Rs 20 lakh |

Tarun Plus additionally requires explicit evidence that the entrepreneur
availed and successfully repaid a prior Tarun loan. A credit score is never used
to infer that history. Missing history returns insufficient information; a
failed condition returns ineligible.

## Program boundary

PMMY is a credit program. Its registered definition has no subsidy benefit,
percentage, calculated subsidy or release simulation. It supports term loan,
working capital or both for income-generating manufacturing, trading and service
micro enterprises and specified allied-to-agriculture activities such as
poultry, dairy and beekeeping. Crop cultivation and personal consumption are not
silently admitted.

The current official metadata records collateral-free institutional credit and
the supported Member Lending Institution categories. It does not guarantee a
sanction, set a lender's interest rate or perform underwriting.

Compatibility with subsidy programs remains unknown unless an official rule is
registered. The existing PMEGP upgradation recognition of qualifying MUDRA
units is unchanged.
