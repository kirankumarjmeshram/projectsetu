# Reference resources

This directory is for safe source material used to validate schemas, financial formulas, scheme rules, and document workflows.

- Never commit private customer documents or quotations containing customer data.
- Never commit copyrighted commercial templates unless redistribution is permitted.
- Use sanitized or synthetic samples only.
- Large source/reference files do not automatically belong in Git; record and store them appropriately.
- Government or public scheme documents may be referenced when permitted. Record their origin, canonical URL or document identifier, scheme/version, publication or effective date, retrieval/last-verified date, and notes.

`samples` is reserved for safe synthetic examples and `schemas` for non-sensitive reference schemas. Generated reports, uploads, OCR intermediates, and AI processing outputs belong outside Git.
